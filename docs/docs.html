Documentation

Everything Veyo Updater can do, in one place.

Getting started

  1. Download VeyoUpdater_Portable.zip from the Releases page and extract it anywhere — or run the one-line install from the home page.
  2. Run VeyoUpdater.exe. No installation, no admin rights needed to start.
  3. The app checks for updates automatically and lists everything with an upgrade available.

Requirements: Windows 10 / 11 (64-bit) with winget — preinstalled on Windows 11, otherwise update App Installer from the Microsoft Store. No VC++ Redistributable, no .NET, no other runtimes.

Updating apps

  • Check for updates — re-scans manually at any time.
  • Per-app Update button — every row has its own button for a single upgrade.
  • Update selected — upgrades only the checked rows, one after another.
  • Update all — upgrades everything in one elevated winget upgrade --all run.
Every upgrade runs elevated: Windows shows a UAC prompt first. If you cancel it, the app tells you admin approval is required instead of failing silently.

Live progress

While upgrading, the status line and the bar under the buttons show:

  • The app currently being updated and its stage: Preparing → Downloading → Installing → Done.
  • A smooth percent bar parsed live from winget's x MB / y MB output.
  • A counter such as 45% (3/19) during batch updates.

Settings reference

Open Settings (top-right button). Everything is stored portably in VeyoUpdater.ini next to the exe — no registry writes.

OptionValuesWhat it does
Start updating automatically after countdownon/off + seconds (5–3600)After a check finds updates, a countdown starts in the status line, then updating begins by itself.
Check for updates automatically everyon/off + minutes (1–1440)Re-scans in the background on a schedule (skipped while an upgrade is running).
After all updates finishDo nothing / Close the app / Shut down the computerRuns only on success. Shutdown uses a 60-second timer — run shutdown /a to abort it.

Example VeyoUpdater.ini:

[Timers]
AutoUpdate=1
CountdownSec=60
AutoCheck=1
CheckMinutes=120
[General]
FinishAction=0

Automation examples

  • Overnight updates: enable the countdown (e.g. 120 s) and set Shut down the computer — start the app before bed and wake up fully updated.
  • Always fresh: enable auto-check every 120 minutes and leave the app minimized.
Overnight shutdown uses a 60-second timer so you can abort it with shutdown /a.

Building from source

You need Visual Studio Build Tools (MSVC + Windows SDK). From the project root:

"%ProgramFiles(x86)%\Microsoft Visual Studio\18\BuildTools\VC\Auxiliary\Build\vcvars64.bat"
rc /fo resources\app.res resources\app.rc
cl /utf-8 /MT /O2 /GL /EHsc /DUNICODE /D_UNICODE /Fe:VeyoUpdater.exe native\src\main.cpp resources\app.res comctl32.lib dwmapi.lib uxtheme.lib user32.lib gdi32.lib advapi32.lib shell32.lib /link /SUBSYSTEM:WINDOWS /LTCG /OPT:REF /OPT:ICF

The /MT flag links the C runtime statically — that is why the exe needs no redistributable. A CMake alternative lives in native/ (see native/build.bat), and an experimental Qt 6 UI in src/.

Troubleshooting

ProblemFix
“winget not found”Update App Installer from the Microsoft Store, then run winget --version.
No updates listed but you expect someTry winget upgrade --include-unknown — some packages report no version.
UAC cancelledNothing was changed. Approve the prompt to let the update proceed.
An update failedThe error message includes the log path (%TEMP%\veyo-updater-*.log).
