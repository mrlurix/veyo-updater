Settings

Timers, automation and what happens when updates finish.

Settings reference

Open Settings (top-right button in the app). Everything is stored portably in VeyoUpdater.ini next to the exe — no registry writes.

OptionValuesWhat it does
Start updating automatically after countdownon/off + seconds (5–3600)After a check finds updates, a countdown starts in the status line, then updating begins by itself.
Check for updates automatically everyon/off + minutes (1–1440)Re-scans in the background on a schedule (skipped while an upgrade is running).
After all updates finishDo nothing / Close the app / Shut down the computerRuns only on success. Shutdown uses a 60-second timer — run shutdown /a to abort it.

Example VeyoUpdater.ini:

[Timers]
AutoUpdate=1
CountdownSec=60
AutoCheck=1
CheckMinutes=120
[General]
FinishAction=0

Automation examples

  • Overnight updates: enable the countdown (e.g. 120 s) and set Shut down the computer — start the app before bed and wake up fully updated.
  • Always fresh: enable auto-check every 120 minutes and leave the app minimized.
Overnight shutdown uses a 60-second timer so you can abort it with shutdown /a.
