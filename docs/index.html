Veyo Updater

A portable single-file winget updater for Windows. Check, review and update all your apps — no installation, no prerequisites.

Download for Windows Read the docs

v1.1.0  •  ~430 KB single exe  •  MIT licensed

Everything you need, nothing you don't

One lightweight window that keeps every winget-tracked app on your PC up to date.

Smart Check

One click lists every available update with a robust parser that handles long names, BOM and odd spacing.

One-Click Updates

Every app row has its own Update button — or update a hand-picked selection, or everything at once.

Safe Elevation

Upgrades always run elevated through a UAC prompt. Cancelling shows a clear message — never a silent failure.

Live Progress

Watch the stage (Preparing → Downloading → Installing → Done), a smooth percent bar and a per-app counter.

Full Automation

Set a download countdown, periodic auto-checks, and what happens when finished — even shutting down the PC.

Zero Footprint

A single ~430 KB exe with the C runtime linked statically. No installer, no registry, no VC++ Redist, no .NET.

How it works

Three steps, under a minute.

1

Run the exe

No setup. It checks for updates automatically on launch.

2

Review the list

Store-style rows show each app with its current and new version.

3

Update

Approve the UAC prompt once and watch live progress per app.

Keep every app up to date.

Free and open source (MIT). Windows 10 / 11, 64-bit.
